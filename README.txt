PROJECT: BELAJAR LIBRARY (ANIMASI)

Menjalankan:
1. Extract ZIP.
2. Buka folder Animasi_Web_PESAT_Persis di Visual Studio Code.
3. Pastikan komputer terhubung ke internet (Bootstrap, Bootstrap Icons, AOS, Animate.css memakai CDN).
4. Klik kanan index.html > Open with Live Server.

Isi disusun mengikuti 16 screenshot yang ada di ZIP sumber: judul Belajar Library, navbar PESAT, header SMA PLUS PGRI CIBINONG, konten 3 baris x 3 kolom dengan animasi AOS, footer dengan ikon sosial, dan pemanggilan AOS.init().

PENTING:
Arsip sumber hanya berisi screenshot instruksi dan video, bukan file asli images/logo/pesat.png dan images/background/bgwhite.jpg. Karena itu kedua aset lokal dibuat sebagai pengganti agar halaman tidak menampilkan gambar rusak. Untuk 100% identik sampai aset asli, diperlukan file logo PESAT dan background asli dari materi guru.
